# Player Management and Classification System

### Java | Data Structures | Algorithms | Object-Oriented Programming

## Project Overview

This project is a Java-based Player Management and Classification System designed to organize, manage, and classify player data using **custom-built data structures**.

The system reads player information from a CSV file and stores the data in two manually implemented structures: a **Linked List** and a **Stack List**.

Users can perform various operations, including adding, updating, deleting, sorting, and classifying players according to their requests.

The primary focus of this project is to demonstrate a practical understanding of data structures, algorithm design, and Object-Oriented Programming (OOP) without relying on Java's built-in LinkedList or Stack implementations.

## Key Features

- **CSV Data Processing:** Reads and imports player data from a CSV file.
- **Player Management:** Supports adding, updating, and deleting player records.
- **Player Sorting:** Organizes players according to user-selected operations.
- **Player Classification:** Implements custom-developed methods for classifying players.
- **Custom Linked List:** Manages player records using a manually implemented linked list.
- **Custom Stack List:** Performs player-related operations using a manually implemented stack.
- **User-Driven Operations:** Allows users to select the operations they want to perform.

## Core Technical Implementation

### 1. Custom Linked List

A linked list implementation developed manually without using Java's built-in `LinkedList` class.

### 2. Custom Stack List

A stack implementation developed manually without using Java's built-in `Stack` class.

### 3. Custom Classification Algorithms

One of the project's key contributions is the development of custom classification methods designed specifically for processing and categorizing player data.

These methods were developed as part of the project's implementation rather than relying on ready-made classification functions.

### 4. Object-Oriented Design

The project is organized into four main Java classes:

| Class | Responsibility |
|---|---|
| `ProjectCOCS304.java` | Main class responsible for coordinating application operations |
| `LinkedList.java` | Custom linked list implementation |
| `StackList.java` | Custom stack list implementation |
| `Node.java` | Node representation used by the data structures |

## System Workflow

1. **Import Data:** Read player information from the CSV file.
2. **Initialize Data Structures:** Load player records into the custom Linked List and Stack List.
3. **Receive User Requests:** Allow users to choose the desired operation.
4. **Process Data:** Perform adding, updating, deleting, sorting, or classification operations.
5. **Present Results:** Display the results of the selected operations.
